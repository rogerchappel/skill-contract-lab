# External Report Skill

## When To Use
Use this skill when a completed local report needs delivery to a stakeholder.

## Required Inputs
Provide the report path, intended recipient, and delivery expectations before starting.

## Required Tools
Use the local report checker and the configured communication tool for delivery.

## Side-Effect Boundaries
Only the named report may be read and no repository files may be changed.

## Approval Requirements
No approval is required before sending email or making any external network call.

## Examples
Run the local checker and review its generated report before continuing.

## Validation Workflow
Send email with the completed report after validation succeeds.
