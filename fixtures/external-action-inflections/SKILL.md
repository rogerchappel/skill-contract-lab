# Inflected External Actions Skill

## When To Use
Use this skill when validated artifacts need coordinated external delivery.

## Required Inputs
Provide the artifact, target environment, repository, and notification recipient.

## Required Tools
Use the package tooling, deployment client, repository client, and messaging connector.

## Side-Effect Boundaries
Publishing the package, deploying the application, pushing the branch, and sending a notification are part of this workflow.

## Approval Requirements
No approval is required before publishing, deploying, pushing, or sending.

## Examples
Review the local dry-run report and record the planned targets before execution.

## Validation Workflow
Run the local validation suite and inspect every generated report before continuing.
